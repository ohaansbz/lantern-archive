Privacy policy

Last updated: 25 November 2026

This policy covers this website and Lantern Archive Uploader, the tool used to publish videos to the Lantern Archive YouTube channel.

Who uses the tool

Lantern Archive Uploader is used only by the owner of the Lantern Archive channel, on the owner's own computer, with the owner's own Google account. It is not offered to the public, and nobody else is asked to sign in to it.

What the tool accesses

With the channel owner's permission, the tool uses YouTube API Services to:

  • upload videos to the Lantern Archive channel and set their titles, descriptions and publishing times;
  • read the channel's own videos and settings;
  • read the channel's own analytics;
  • read and reply to comments on the channel's own videos.

How that data is used and stored

The data is used only to run the Lantern Archive channel. The access token Google issues is stored on the channel owner's computer. Nothing obtained through YouTube API Services is sold, shared with third parties, or used for advertising, and no data about viewers is collected beyond what YouTube itself shows the channel owner.

Removing access

The channel owner can revoke the tool's access at any time on the Google security settings page: security.google.com/settings/security/permissions. Revoking access makes the stored token useless; the token file can then be deleted from the computer.

This website

This website has no accounts, forms, cookies or analytics of its own. It is hosted on GitHub Pages, and GitHub may log technical information such as IP addresses as described in GitHub's privacy statement.

YouTube and Google

The tool uses YouTube API Services. Use of YouTube is governed by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Contact

Questions about this policy can be sent through the Lantern Archive channel on YouTube.
